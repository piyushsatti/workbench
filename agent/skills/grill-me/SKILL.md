description: A relentless interview to sharpen a plan or design. Run only when the user asks for it by name.
---

Read [the grilling procedure](references/GRILLING.md) and run that interview
for the user's plan, decision, or idea. The procedure is bundled here so this
skill works without invoking another host-specific skill command.

If the host has no sub-agents, look up needed facts in this session. Ask
independent frontier questions while resolving those facts, and wait to ask
only the questions that depend on them.
